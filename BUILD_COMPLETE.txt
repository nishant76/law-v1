📞 SUPPORT

Question: How do I run the migration?
Answer:   See MIGRATION_GUIDE.md or run: python run_migrations.py

Question: What tables were created?
Answer:   See SCHEMA_DOCUMENTATION.md (complete reference, 500+ lines)

Question: How are firms isolated?
Answer:   Every law table has firm_id column (multi-tenancy enforced)

Question: Can I delete records?
Answer:   No hard delete. Use soft delete: UPDATE table SET deleted_at=NOW()

Question: Where's the JWT validation?
Answer:   Middleware stub in backend/middleware/logging.py (ready for Phase 1+)

Question: How do I add a new table?
Answer:   1. Create model in backend/models/
           2. Add to __init__.py
           3. Create migration: alembic revision --autogenerate
           4. Run migration: alembic upgrade head
